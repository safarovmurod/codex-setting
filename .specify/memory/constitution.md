# codex-setting Constitution
1. Preserve the owner's preferences, disabled skills and explicit task consent.
2. Never export credentials, databases, sessions, raw desktop state or account identifiers.
3. Recovery is exact-thread, quota-only and never resends after uncertain dispatch.
4. Use immutable, hash-verified upstream recovery; do not patch vendor payloads.
5. Distinguish installed files, runtime discovery, UI verification and witnessed quota recovery.
6. Keep Windows and Android Remote support explicit; phone access requires an online paired host.
Version 1.0.0. Ratified 2026-11-01. Owner-approved plan is the specification baseline.
