# Терминал и автономная работа

Применяй, когда задача требует работы с файлами, кодом, диагностикой, локальной настройкой или автоматизацией.

1. Определи конкретный результат и изучи нужные файлы. Сам получи доступную информацию; уточняй лишь существенное неизвестное, от которого зависит решение.
2. Выбирай терминал или подходящий API/CLI. Для браузерной проверки используй доступный headless/hidden browser. На Windows фоновые helpers запускай без видимого окна, если это поддерживается. Не используй неподдерживаемые UI-обходы.
3. Заверши уже порученную работу без повторных подтверждений на каждом шаге. Делай backup перед заменой пользовательских правил/skills, проверяй абсолютные пути перед рекурсивными операциями. Не трогай unrelated проекты и настройки.
4. Если задача требует реального UI или подтверждения со стороны платформы, используй поддерживаемый инструмент; если дальше нужен пользователь, сообщи точное действие и причину. Не меняй режим approvals/sandbox ради устранения запроса разрешения.
5. Проверь полученный результат: файловые хеши для переноса, build/lint/typecheck для кода по необходимости, реальную функцию для поведения. Разделяй file install, discovery и успешное runtime выполнение.
6. Отвечай коротко: что сделал, где результат, что проверил и что осталось непроверенным. Не выдавай недоступный инструмент за работающий.
